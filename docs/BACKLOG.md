# 后续任务清单

当前代码已修复 VGGT 可复现的双栏排序、公式/表格原图核对和阅读页同步。以下事项尚未达到可宣称完整支持的程度，继续开发时按准确性优先处理。

1. **复杂版式基准集**：收集单栏、双栏、跨栏标题/图/表、脚注、References、Appendix、跨页段落的 PDF 及人工标注顺序。当前基于中线和跨栏块分段，复杂不规则版式只保留原图与待核对状态。
2. **公式结构校验**：为显示公式建立人工确认后的 LaTeX 与原图双存储，识别公式编号和变量定义；对视觉模型输出做符号级核对。当前解释基于图像，但自动转写不能当成已验证公式。
3. **表格合并与跨页**：为多层表头、rowspan/colspan、无边框和跨页表格建立可靠单元格合并；保留粗体/斜体最佳值标记。现阶段单元格 `rowspan/colspan` 是普通网格占位值，需核对。
4. **图形覆盖率**：识别 PDF 矢量绘图和组合图，建立图号与图注的一对一校验。当前主要识别嵌入式位图。
5. **翻译质量**：每篇论文术语表、公式和表格标签的受约束翻译、原文哈希校验、重复 ID 与语义错配评估；目前仅有 ID 映射和缺失数检查，无法证明每条译文语义准确。
6. **并发与免费额度**：多标签页的版本冲突控制、翻译任务暂停/恢复、速率限制与配额耗尽分离、token 用量统计和幂等任务队列。当前逐批缓存结果，不自动切换付费模型。
7. **目标设备回归**：用实际麦克风、英文/中文系统声音、锁屏/后台和 Finder 连续拖拽测试；这些能力受浏览器与操作系统限制。
8. **大 PDF 性能**：已按当前页限制译文 DOM，仍需对数百页论文做 PDF 渲染、索引与缓存性能测试。

继续执行前，先复制 `backend/data/` 做备份，运行后端与前端测试，再选取待处理 PDF 手动核对原图、坐标、译文和问答依据。所有重新解析必须保持旧段落 ID 与学习记录；匹配失败时不得自动覆盖。
