# PaperMind V5 本地验收记录

## 本轮交付

- 用同一套受限上下文包处理选区问答和公式、图表解释：段落原文与译文、章节、邻近段落、相关对象及同一来源的近期对话一同检索；只有核对过的短引文才作为可点击证据返回。
- 英文 PDF 和中文译文的「问 AI」改为先固定来源，再让用户输入问题。来源可移除，连续追问沿用来源，历史中的每条提问保留各自引用。找不到精确段落时按页回退，不显示虚假的精确高亮。
- 公式提供简明和深入两种按需解释，保留 PDF 原图和放大入口。解释结果按图像、上下文、模型、模式及提示词版本缓存。深入解释明确要求标示 AI 辅助推导；图表使用原图生成说明。
- 问答和公式说明有加载、重试、取消或过期响应保护。问答可选模型路由，未设置任务模型时沿用现有 `GEMINI_MODEL`。新增 SQLite 缓存表和问答来源列，迁移不重建已有表。

## 验证

- 后端：`PYTHONPATH=backend .venv/bin/python -m unittest discover -s backend/tests -q`，26 项通过。新增测试覆盖英文选区、中文译文与英文原文关联、连续追问、页级回退、错误精确锚点过滤、内部伪引用清理、公式简明缓存、深入解释历史及公式追问附带原 PDF 图像。
- 前端：`cd frontend && npm test`，13 项通过；`npm run build`，TypeScript 与生产构建通过。
- Chrome 本机临时数据验收：打开合成 PDF；原图放大成功；PDF 原文拖选后点「问 AI」只显示固定引用且未发送请求；输入自定义问题后 Gemini 返回回答，历史出现原文链接；点击历史来源可定位；简明公式解释显示且 KaTeX 数学内容可读；切换原版模式后 PDF 仍正常显示。测试数据写在 `/private/tmp`，未修改仓库中的 `backend/data`。

## 尚有限制

- PDF 不提供可靠数学结构时保留高清原图，不从乱码或不确定的提取文本猜测 LaTeX。复杂公式的 PDF 原生结构识别、扫描件 OCR 尚未实现。
- 中文译文与英文句子的精确几何映射不可得时按段落定位。复杂跨栏、跨页选区仍可能只能定位到段落或页。
- 浏览器手工验收使用了英文合成 PDF；中文选区路径已通过后端集成测试，但尚未用真实复杂论文逐页验收。深入公式模式已通过图像传参和缓存测试，未对所有公式形态做人工事实审校。
- 本轮未测试物理麦克风、移动设备后台播放，也未增加流式输出。现有语音 API 的浏览器限制仍适用。
- 本轮未将改动推送到远程仓库，也未修改已有用户论文数据。
